Sıra önemli: havuzu likidite eklemeden ÖNCE exclude et, yoksa havuz decay yer.
  1. Router'ın factory'sinde createPair(MM, WETH) çağır → pair adresini al.
  2. Aşağıdan addPair(pair) → havuzu decay'den muaf tut.
  3. Vakıf cüzdanından addLiquidityETH ile MM/ETH likiditesini ekle (LP sende kalır, sen yönetirsin).
  4. Ek pair'ler (MM/NVDA…): createPair → addPair. Motor swap'ları hep MM/WETH'ten döner.
  5. Bittiğinde renouncePairManager() → token tamamen otonom, scanner tamamen temiz.
